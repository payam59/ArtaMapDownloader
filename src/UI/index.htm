    Help & about
    Arta Map Downloader version 1.0.0

    Download map tiles from Bing, Google, OpenStreetMap, ESRI or any tile server whose URL takes {x}, {y}, {z} or {quad}, for an area you draw on the map, into a folder of tiles, an MBTiles file or a Repo file. Downloads run on this computer's local server, can be stopped and resumed, and an existing tile folder can be opened to see what is there and fetch only what is missing.

    What is new compared with the original
    • Resume a stopped or interrupted download; only missing tiles are fetched again.
    • Open an existing tile folder or MBTiles file, with a green / red coverage overlay and a have / missing table per zoom.
    • An editable download rectangle with a live missing-tile count.
    • Fixes for the slowdown and memory growth on large downloads.
    • Listens on this computer only (localhost) by default.

    Arta Map Downloader is based on Map Tiles Downloader by Ali Ashraf (MIT licence). It was enhanced, bug-fixed and extended with new features by Arta Cyber Inc.
